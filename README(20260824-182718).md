# Abu Dhabi Power Map — V1

Database-first starter for the Abu Dhabi Core Power & Industry Network.

## Core files
- `abu_dhabi_power_map.db` — SQLite database; source of truth
- `schema.sql` — database schema
- `people.csv`, `institutions.csv`, `roles.csv`, etc. — import/export tables
- `build_hub.py` — rebuilds the Hub from SQLite
- `abu_dhabi_power_hub.html` — self-contained interactive network map
- `data_dictionary.md` — operating rules

## Design principle
Facts and analysis are stored separately.

**Facts:** person, institution, role, board seat, dates, sources, verification status.
**Analysis:** power score, operating relevance, access relevance, strategic relevance.

## Recommended scale
- Top Power: ~20
- Sector Leaders: ~40
- Operational Key People: ~60–90
- Total V1 target: 100–150 people and 75–100 institutions.

## Rebuild the Hub
```bash
python build_hub.py
```

## Quality rule
Important current roles should ultimately have an official source, access date, appointment/end dates
where known, and `verification_status = verified`.

The current records are a starter backbone. `needs_source` means the row still requires official verification.
